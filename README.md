# 📚 Atividades de Aula

Bem-vindo(a) ao meu repositório de **atividades feitas em aula**! Aqui você vai encontrar exercícios, projetos e anotações organizadas por disciplina e semestre. Esse repositório funciona como meu portfólio de aprendizado e também como um espaço de consulta e revisão. 🚀

---

## 🗂️ Organização

As atividades estão organizadas da seguinte forma:

📁 nome-da-disciplina/ ├── 📁 Nome do trabalho/ ├── 📝 Arquivos.java


**Exemplo:**

📁 Trabalhos Java/ ├── 📁 SistemaPagamento/ ├── 📝 Main.java


---

## 🛠️ Tecnologias Utilizadas

Dependendo da disciplina, os conteúdos podem envolver:

- 💻 Python
- ☕ Java
- 🌐 HTML/CSS
- 📊 SQL
- 🧠 Lógica de Programação
- 🧪 JavaScript
- 📘 Markdown para anotações

## 🎯 Objetivo

Esse repositório tem como objetivos:

- Acompanhar minha evolução nas disciplinas
- Ter um espaço organizado para revisar conteúdos
- Compartilhar conhecimento com colegas e interessados
